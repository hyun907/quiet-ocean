# 🌊 Quiet Ocean — 조용한 바다

조용한 바다 위에 있는 듯한 느낌을 주는 감성적인 인터랙티브 웹 경험입니다.
시간대에 따라 하늘과 바다의 색이 변하고, 철썩이는 파도 소리와 함께 주변을 둘러볼 수 있습니다.

**기술 스택**: Vite · TypeScript · Three.js (shader 기반 수면, 포스트프로세싱)

## 설치 및 실행

```bash
npm install      # 의존성 설치
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 타입 체크 + 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```

## 조작 방법

| 조작 | 동작 |
| --- | --- |
| 마우스 드래그 | 시야 회전 (상하 각도 제한, 부드러운 감쇠) |
| 휠 스크롤 | 줌 (FOV 조절) |
| 화면 클릭 | 파도 소리 시작 (브라우저 자동재생 정책 대응) |

접속하면 **실제 한국 시각(KST)에 맞는 시간대**로 시작하고, 30초마다 실제 시각을 따라갑니다.
시간 슬라이더를 직접 움직이거나 자동 흐름을 켜면 실시간 추적이 해제됩니다.

오른쪽 아래 컨트롤 패널:

- **시간** — 새벽 → 아침 → 낮 → 노을 → 밤을 슬라이더로 조절
- **파도 세기** — 0%~200%
- **소리 켜짐/꺼짐** — 파도 효과음 토글
- **자동 흐름 / 시간 고정** — 하루(약 4분)가 자동으로 순환

## 파도 소리 음원 교체

`public/audio/waves.mp3` 경로에 루프 가능한 파도 소리 mp3를 넣으면 그대로 사용됩니다.
(무료 음원: [freesound.org](https://freesound.org), [pixabay.com](https://pixabay.com/sound-effects/) 등)

파일이 **없어도 동작합니다** — 이 경우 WebAudio로 합성한 파도 소리(브라운 노이즈 + 느린 스웰)가 자동으로 재생됩니다.

## 프로젝트 구조

```
src/
├── main.ts               # 진입점 — 모듈 조립, 렌더 루프, 시간대 팔레트 적용
├── core/
│   ├── renderer.ts       # WebGL 렌더러 (ACES 톤매핑, 픽셀비율)
│   ├── camera.ts         # 수면 위 낮은 시점 카메라
│   └── controls.ts       # 마우스 드래그 시야 컨트롤 (감쇠, 피치 제한, FOV 줌)
├── world/
│   ├── ocean.ts          # shader 수면 + 해안 모래 평면
│   ├── sky.ts            # 그라데이션 하늘 돔 (태양/달 포함)
│   ├── stars.ts          # 밤에 나타나는 별 (깜빡임)
│   └── lighting.ts       # 씬 보조 조명
├── time/
│   └── timeOfDay.ts      # 시간대 키프레임 팔레트 보간, 태양 방향 계산
├── audio/
│   └── oceanAudio.ts     # mp3 루프 재생 + WebAudio 합성 폴백
├── ui/
│   ├── panel.ts          # 글래스모피즘 컨트롤 패널
│   └── style.css
├── post/
│   └── composer.ts       # bloom + 비네트 + OutputPass(톤매핑/sRGB)
└── shaders/
    ├── ocean.vert.glsl   # 사인파 합성 수면 변위 + 해석적 법선
    ├── ocean.frag.glsl   # 수색/Fresnel/글리터/foam/안개
    ├── sky.vert.glsl
    ├── sky.frag.glsl     # 하늘 그라데이션 + 태양/달
    ├── stars.vert.glsl
    └── stars.frag.glsl
```

## 구현 노트

- **파도**: 물리 시뮬레이션 없이 Gerstner 파 6개 + 해안 브레이커를 합성합니다.
  Gerstner 파는 정점을 수평으로도 밀어 마루가 뾰족하고 골이 평평한 실제 파도 형태를 만들고,
  편미분을 함께 누적해 법선을 해석적으로 계산하므로 가볍고 안정적입니다.
- **잔물결**: 시작 시 절차적으로 생성한 타일링 노멀맵(외부 에셋 불필요)을
  두 배율/방향/속도로 스크롤해 합성합니다. 밉맵 + 이방성 필터링으로 멀리서도 깨끗합니다.
- **반사**: CubeCamera로 하늘(태양 글로우·그라데이션·달)을 HDR 큐브맵에 구워
  수면이 실제 하늘을 반사합니다. 시간대가 바뀔 때마다 다시 굽습니다.
- **해안**: 카메라 뒤쪽(z=+150)에 해안선이 있어, 뒤돌아보면 파도가 밀려와 부서지는
  foam 라인과 물가 거품띠가 보입니다.
- **시간대**: 새벽/아침/낮/노을/밤 5개 키프레임 팔레트를 smoothstep으로 보간합니다.
  하늘·바다·안개 색, 태양 고도/방위, 노출, 별/달 표시량이 함께 변합니다.
  밤에는 수면 반사 광원이 태양에서 달로 자연스럽게 전환됩니다.
- **성능**: 모바일(터치 기기)에서는 수면 격자 밀도·픽셀비율을 낮추고 bloom을 생략합니다.
